List every report you can read, across your Teams and Portfolios, with `lh report list`, without naming an owner, or with the MCP tool `lighthouse_report_list`. An older Lighthouse is told to upgrade, and a reader who is not signed in is told how to sign in, and `lh report list --team-id` without an id is refused instead of listing every report. With usage data on, listing every report is counted as AllReportsListed, by name alone.
